# Limitations and release blockers

No LICENSE exists. The repository owner must choose licensing terms before an open-source release. A license has deliberately not been selected on the owner's behalf. A permissive research/software license such as Apache-2.0 or MIT could be considered by the owner; this recommendation grants no rights.

The unified laboratory supports native templates. External framework experiments remain in the existing integration workflow. It does not support arbitrary imported executable scenarios or arbitrary new tool definitions. Live autonomous laboratory runs are disabled. Dataset VALIDATION is not independent of development. Current held-out fixtures are public and same-author.

The final research UI provides functional forms, measured JSON statistics, datasets, hypotheses, reports and downloads. It does not yet provide all requested statistical visualizations, model comparison controls, report history, or the complete twenty-step trajectory browser workflow. Recorded ablations combine predictions; they are not fresh causal intervention experiments.

The final demonstration covers scripted/autonomous native research, reporting and bundle verification. It does not yet orchestrate every requested adversarial/framework/regression/security demonstration in one command. Optional Docker, PostgreSQL, live APIs and all supported external framework versions need separate evidence.

Prompt injection, paraphrase, unobserved context, compromised host code and policy coverage remain limitations. This system does not solve alignment or guarantee prevention of arbitrary harms.
