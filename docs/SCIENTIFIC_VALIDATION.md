# Scientific validation

Result validation checks dataset and result hashes, trusted scoring fingerprints, trial identifiers, observations, cutoff/evidence references and recomputed metrics. It flags failures without rewriting historical results. Integrity checks do not prove semantic correctness or absence of every possible leakage channel.

Metrics preserve undefined denominators as null and failed predictions as unknown. Count-based F1 is zero when there are errors and no true positives. Paired effects weight scenario template clusters equally. Synthetic repeated fixtures do not receive inferential confidence intervals. Wilson intervals require independent Bernoulli observations; the utility is tested against known numerical values. Optional clustered bootstrap and Holm correction utilities do not automatically create significance claims.

Critical-checkpoint measurements cannot establish earliest detection. Same-author templates, shallow tool families and exact-value detectors limit generalization.
